소스 업로드 배포

            

              
              
              
              
            

            
zip / tar.gz 파일 업로드 (최대 800MB) → Dockerfile 감지/자동생성 → 이미지 빌드 → 컨테이너 배포. Dockerfile 없으면 언어 자동 감지 (Node.js, Python, Go, Java, HTML). Cloudflare 경유 시 100MB 제한에 걸립니다 — 큰 파일은 직접 IP(http://20.20.6.248:8000) 사용 또는 Git URL 배포를 이용하세요.

            

          

          

          

          
          

          

            
Git URL 배포

            

              
              
              
              
              
            

            

              🔒 Private:
              
              또는 저장된 시크릿:
              
            

            
공개 repo는 토큰 없이, private repo는 GitHub Personal Access Token(PAT)을 입력하거나 저장된 시크릿에서 선택하세요. 토큰은 로그·저장·응답에 노출되지 않습니다. depth=1 clone → 동일 파이프라인.

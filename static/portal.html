        💻 내 PC에서 직접 빌드한 이미지를 내장 registry에 push 하기 (docker CLI)
        
registry 상태 확인 중...

        

          
          
          
          
        


        
1. registry를 insecure(HTTP)로 등록 — 최초 1회
          
내장 registry는 사내망 전용 HTTP registry입니다. Docker가 HTTPS 없이 접속하도록 허용해야 합니다.

          
Docker Desktop (Mac/Windows): Settings → Docker Engine 에 아래 항목 추가 후 Apply & restart

            Linux: /etc/docker/daemon.json 에 추가 후 sudo systemctl restart docker

          

        


        
2. 이미지 빌드
          
클러스터 노드는 x86(amd64)입니다. Apple Silicon(M1~M4) Mac에서는 반드시 --platform linux/amd64를 지정하세요.

          

        


        
3. 태그 지정 후 push
          
이미지 이름에 registry 주소가 붙어 있어야 해당 registry로 push 됩니다.

          

        


        
4. 확인 및 기동
          
push 된 이미지는 위 "🚀 이미지로 서비스 기동"의 이미지 목록에 나타납니다. 아래 버튼으로 바로 입력할 수 있습니다.

          

          

        


        
⚠ registry 주소는 사내망(VPN 포함)에서만 접근 가능하며 외부 도메인(Cloudflare)으로는 push 할 수 없습니다. 인증이 없으므로 이미지에 비밀값(API 키, 비밀번호)을 넣지 말고 "🔑 내 시크릿"으로 주입하세요. 같은 이름:태그로 push 하면 덮어쓰므로 이름 앞에 팀/계정명을 붙이는 것을 권장합니다(예: 계정명-myapp).

      

      


      
      

      
계정 전용 PostgreSQL / MySQL 데이터베이스를 기동합니다. 기동 후 표시되는 내부 엔드포인트(호스트:포트)로 다른 서비스에서 접속할 수 있습니다.

      

        

          
          
        

        

          
          
          
        

        

          
        

        
⚠️ DB와 이를 사용하는 서비스는 같은 노드에 배치하는 것을 권장합니다. 비밀번호는 암호화되어 저장되며 로그에 노출되지 않습니다.
